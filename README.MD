# School Attendance System
A simple, offline-first attendance system for Kenyan schools. Built to replace paper registers.

## 🎯 Features
- Mark attendance daily
- View student list
- Store data locally (no internet needed)
- Export to Excel

## 🛠️ Tech Stack
Python, HTML/CSS, Git

## 🚀 How to run
python app.py
